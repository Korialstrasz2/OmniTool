{{ 'Browser History Cleaner' if kind == 'history' else 'Cookie Cleaner' }}

Native browser operations, not direct edits to browser databases.

Extension required

Install once in each browser profile

The repaired cleaners run in an included, local browser extension. OmniTool does not read browser cookie values, overwrite SQLite files, close browser processes, or guess which profile to modify. This page does not automatically detect installation.

Chromium package Firefox package

Chrome / Edge / Brave: extract the Chromium ZIP into a permanent local folder. Open your browser's Extensions page, enable Developer mode, select Load unpacked, and choose that extracted folder. Use a current Chromium-based browser; the manifest requires Chromium 130 or later.

Firefox: the package targets Firefox 145 or later. Extract it, open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, and select manifest.json. This temporary installation disappears on restart; persistent installation requires signing/distribution work not included here. Firefox runtime acceptance has not yet been performed.

Pin the extension, click its toolbar button, then choose Open in a full tab. The active browser profile is the scope. Cookie stores/containers are selected inside the extension; other installed browser profiles are not enumerated.

Preview → select → encrypted backup → verify → confirm

Permissions are requested only when you explicitly grant History access or Cookies plus HTTP(S) site access. No records are selected automatically. Protected-cookie hosts are stored only in that extension profile, with exact matching by default and an explicit subdomain option.

Create an encrypted backup of the exact selection, save it, reopen it, and verify the passphrase. Only then can a typed DELETE N confirmation apply the selection. Changed or shadowed records are skipped. Cookie values are never printed in the interface. The extension has no content scripts or network transport.

Close affected site tabs and pause other activity before applying. Browser APIs do not offer a multi-record transaction; websites, workers, and sync may change records during cleanup. Review the per-record results. Deleting cookies may sign you out.

Recovery has limits

Restore encrypted backups in their original browser profile. Existing or expired cookies are skipped, and restoring a cookie does not restore a server-side session. Missing history URLs can be re-added, but their original visit times, counts, and transitions are not recreated. Backups preserve those details for inspection, not exact history rollback.

The extension never requests bookmarks permission. It does not erase server-side activity, other devices, or all site storage. Public suffixes are not guessed: example.co.uk is not collapsed to co.uk.

See docs/SAFE_MAINTENANCE.md for limits, permissions, testing, and the backup format. Test with a disposable browser profile before daily use.
