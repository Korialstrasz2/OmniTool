Backend setup and privacy

Start your local model separately. Set OMNITOOL_PROMPT_URL before launching OmniTool; the default is http://127.0.0.1:5001. Only an explicit HTTP loopback origin is accepted. Backend discovery, redirects, cloud services, and silent fallback requests are disabled.

For a local chat-completions server, also set OMNITOOL_PROMPT_KIND=local-chat and OMNITOOL_PROMPT_MODEL. Stopping ends OmniTool's worker; the model server may continue its own generation. Results expire after ten minutes and are not written to browser storage or workspace logs.
