Add to your workspace

Public tool

Add a folder under tools/ with a Python entrypoint and tool.json. The catalog discovers it automatically. No UI or Flask route changes are needed.

Locked tool or folder

Keep plaintext outside your Git working tree. Use the local sealing command below; it prompts for your passphrase in the terminal.

python -m omnitool_core.vault seal /private/my-tools --kind folder --name "My tools"

Only the randomly named vaults/*.otvault file belongs in the public repository. For one tool, use --kind tool and include exactly one tool.json.

Sealing does not delete original plaintext or erase Git history. Store your passphrase in a password manager. There is no reset or recovery backdoor.

See docs/ADDING_TOOLS.md and docs/VAULT_SECURITY.md for the manifest and security model.

Unlock bundle

Metadata stays hidden until the passphrase is verified. Unlocking does not execute code.

The lease is fixed, not extended by polling. Active private jobs are stopped when it expires.

Only run code you trust. Encryption is not a sandbox. Downloaded files are plaintext and are not re-locked by OmniTool.
